## What's Changed

- Kept project cards in a two-column layout, so a single project stays half-width instead of stretching across the screen.
- Moved Recently Stopped, Application Services, Other local listeners, and old unassigned notes into a slide-out More services sidebar.
- Replaced process-stop confirmation dialogs with one-click Stop actions and inline loading spinners for individual services, selected services, and whole projects.
- Added Stop actions for verified application services such as Ollama, while keeping system processes and the dashboard protected.
- Made stopped servers disappear sooner, with immediate updates after a confirmed stop and faster detection when a server is stopped outside the app.
- Removed the Show stopped checkbox and Add Project option from Servers.
- Added smooth sidebar transitions, keyboard focus handling, and Escape dismissal across light and dark themes.
- Fixed Mac stop actions reporting a failure after the process had already stopped, and kept servers stoppable after restarting them from the dashboard.
- Improved Mac Python server recognition and prevented live services from appearing in Recently Stopped after reopening the app or temporarily losing process details.
- Corrected Mac CLI version detection for launcher aliases such as Cargo and Rust, and preserved comparison history when a CLI scan is incomplete.
