## What's Changed

- Reduced background work by sharing process scans and reading CPU and memory once per process, even when several services use it.
- Kept server and health updates from redrawing unrelated tabs, and stopped the background from animating while the dashboard is idle.
- Made the app smaller by removing unused dependencies and packaging a single copy of the interface libraries.
- Added smooth opening and closing transitions to tabs, drawers, dialogs, and expandable details, with support for reduced motion.
- Kept Save and Reset to defaults visible at the bottom of Settings while the options scroll.
- Grayed out Save until a setting changes. Reverting your edits disables it again.
