## What's Changed

- Rebuilt the desktop app in Rust with Tauri. The dashboard keeps the same React interface, colors, and controls.
- Cut the Windows installer from about 96 MiB to about 5 MiB by using the system WebView2 runtime. With the same servers running, the dashboard used about 40% less private memory on Windows.
- Carried over settings, projects, notes, pins, recent scripts, CLI inventory, and appearance preferences when upgrading from Electron.
- Fixed CLI scans that could miss tools in quoted Windows install paths or point a pipx package at the wrong installation folder.
- Fixed health checks that could show a service as healthy when it sent a malformed HTTP response.
- Fixed Settings overwriting a newer scan interval or notification preference when saving a shortcut.
- Added a direct upgrade to the Rust app through the existing Windows updater and Sparkle on Mac.
